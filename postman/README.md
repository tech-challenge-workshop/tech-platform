# Postman collection

`tech-challenge.postman_collection.json` — 25 requests across 5 folders, every
one going through Kong. Nothing talks to a service directly.

## Before you start

Two variables have to be filled in. Neither is committed.

**`baseUrl`** — Kong's load balancer, which changes every time the cluster is
recreated:

```sh
kubectl get svc -n kong kong-gateway-proxy \
  -o jsonpath='{.status.loadBalancer.ingress[0].hostname}'
```

Use `http://localhost:8000` to run against the local compose instead.

**`adminApiKey`** — from the generated secrets:

```sh
grep '^ADMIN_API_KEY=' k8s/.secrets.env | cut -d= -f2-
```

Set both under *Collection → Variables → Current value*.

## Running it

Run the folders in order. Tokens and ids are captured into collection variables
by the test scripts, so nothing has to be copied by hand.

| Folder | What it does |
| --- | --- |
| 1 · Autenticação | Issues the admin and customer tokens the rest depend on |
| 2 · Catálogo | Seeds part, service, customer and vehicle; stores their ids |
| 3 · Saga completa | Opens a work order and drives it to `FINISHED` |
| 4 · Compensação | Fails a repair and watches the saga unwind |
| 5 · Segurança | 401 without a token, 403 with the wrong role, 200 on a public route |

**Give folder 3 a second or two between requests.** Opening the order starts a
distributed transaction: parts are reserved and the quote is generated by two
other services, so "Consultar OS" right after "Abrir OS" may still show
`RECEIVED` rather than `AWAITING_APPROVAL`.

The plate in "Criar veículo" is unique — change it between runs, or the request
returns a conflict and the vehicle id stays empty.

## Running it headless

```sh
newman run tech-challenge.postman_collection.json \
  --env-var baseUrl="http://$NLB" \
  --env-var adminApiKey="$ADMIN_API_KEY"
```

For a pass/fail check without Postman, [`../scripts/smoke-test.sh`](../scripts/smoke-test.sh)
covers the same ground in 23 assertions and about 40 seconds.

## Swagger

Each service also publishes OpenAPI. The gateway does not expose it, so reach it
directly:

```sh
kubectl port-forward -n tech-challenge svc/work-order-service 3000:3000
# http://localhost:3000/docs
```

Ports: work-order `3000`, billing `3001`, execution `3002`.
